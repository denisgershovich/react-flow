# Composer UI

A React + TypeScript + Vite application with React Compiler enabled.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```

## Tech Stack

- React 19
- TypeScript
- Vite
- React Compiler

## Project Structure

- `src/` - Source code
- `public/` - Static assets
- `index.html` - Entry point
